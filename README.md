# PolicyLens  
### AI-Assisted Public Comment Analysis for Trust, Transparency, and Policy Insight

## Overview

PolicyLens is an AI-assisted qualitative analysis tool designed to turn large-scale public comments, reviews, and online discussion into structured insights for research and decision-making.

The project began with a simple question:

**How can AI help synthesize messy public feedback without hiding the uncertainty behind the evidence?**

As generative AI becomes a common interface for search and recommendation, users increasingly receive clean, fluent answers without seeing how those answers were formed. This creates a trust problem: weak evidence can appear more reliable than it actually is.

PolicyLens was built as a lightweight prototype to explore that challenge through both product design and policy analysis.

---

## What the Tool Does

PolicyLens takes open-ended user queries and analyzes public-facing text such as:

- online reviews
- public comments
- discussion threads
- recommendation-style user feedback

It then organizes this information into structured outputs including:

- **Key Themes** — recurring discussion topics and common user concerns
- **Sentiment Summary** — positive, negative, and mixed reactions
- **Recommendation Signals** — commonly mentioned suggestions or preferences
- **Credibility Notes** — indicators of uncertainty, repeated claims, or limited evidence
- **Decision-Oriented Summary** — concise synthesis for policy or research use

---

## Why I Built It

I built this project to test how far a lightweight AI workflow could go in transforming messy qualitative feedback into something useful for analysis while keeping the evidence trail visible.

During testing, several patterns emerged:

- **Specific queries produced stronger results.** Narrow prompts with clear criteria led to more useful and targeted outputs.
- **Broad queries often produced generic answers.** AI tended to repeat popular or highly visible narratives rather than evaluate evidence quality.
- **Popularity was not always reliability.** Frequently repeated claims could reflect genuine consensus—or marketing, SEO, or platform amplification.
- **Good AI synthesis still requires human judgment.** AI can organize information quickly, but it cannot independently verify whether the evidence is representative or trustworthy.

These observations became the basis for a broader policy memo on **AI-generated recommendations and the problem of trust**.

## Policy & Governance Focus

This project sits at the intersection of:

- AI product design
- public policy analysis
- trust & transparency in recommendation systems
- human-centered AI governance
- qualitative research workflows

The broader policy question behind the project is:

> When AI becomes the interface between users and public information, what should the system show about the evidence behind its answer?

PolicyLens explores one possible response:
using AI to reduce the cost of synthesis while preserving visibility into uncertainty, evidence quality, and source limitations.

## Technical Implementation

Built with:

- Python
- Streamlit
- GitHub
- Prompt engineering workflows
- LLM-assisted text synthesis
- Structured qualitative analysis

Core workflow:

1. User submits a topic or recommendation query
2. Text inputs are grouped into themes and sentiment patterns
3. Recommendation signals are extracted
4. Credibility / confidence indicators are surfaced
5. Results are returned in a decision-friendly summary format
